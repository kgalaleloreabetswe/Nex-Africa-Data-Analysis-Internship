# Week 1 — Data Collection, Cleaning & Preparation

## Overview

Week 1 focused on preparing raw data for analysis by inspecting, cleaning, transforming, and structuring the dataset into an analysis-ready format.

The objective was to develop a clean and reliable dataset that could be used for the analysis and visualization stages of the internship.

## Objectives

- Inspect and understand the raw dataset
- Identify data quality issues
- Clean and transform the data
- Handle missing and inconsistent values
- Check for duplicates and formatting issues
- Structure the dataset for analysis
- Document the data preparation process

## Files

| File | Description |
|---|---|
| `Raw_Data` | Original dataset provided for the analysis |
| `Cleaned_Data` | Cleaned and structured version of the dataset |
| `Data_Analysis` | Excel workbook containing the data inspection, cleaning, and analysis work |
| `Week_1_Document` | Documentation of the data preparation process, findings, and methodology |

## Tools Used

- Microsoft Excel
- Data Cleaning & Preparation
- Power Query

## Key Outcome

The raw dataset was transformed into a clean, structured, and analysis-ready dataset that can be used for further exploratory analysis, visualization, and business reporting in the subsequent stages of the internship.
